## 〇、v2.2.0 更新了什么

在 v2.1.0 内置 Local ADB 的基础上，把「连不上无线调试」这个最常见的坑基本填平：

| 改动 | 说明 |
|---|---|
| 端口框支持 `IP:端口` | 现在可以直接填 `192.168.1.5:38421`，也可以只填 `38421` |
| 自动探测候选主机 | 连接时依次尝试：用户填的 IP → `127.0.0.1`（本机回环）→ 手机当前 WiFi IPv4，总有一个能通 |
| 端口框改文本类型 | 不再被数字键盘限制，最长 25 字符 |
| 新增网络权限 | Manifest 增加 `INTERNET`、`ACCESS_NETWORK_STATE`、`ACCESS_WIFI_STATE` 与 `usesCleartextTraffic`（无线调试走明文 TCP，必须允许） |
| Socket 15 秒超时 | 主机不通时快速失败并继续试下一个候选，不会长时间卡住 |

## 一、v2.1.0 是什么（重大变化）

v1 依赖 **Android 无障碍服务（AccessibilityService）** 模拟滑动。v2.1.0 完全重构为**单 App 全包**方案：

| | v1.0.0 | v2.1.0 |
|---|---|---|
| 底层原理 | 无障碍服务 dispatchGesture | App 内置纯 Kotlin **ADB 协议引擎** |
| 需要无障碍授权 | 是 | **否** |
| 需要 Shizuku | 否 | **否** |
| 需要 Root | 否 | **否** |
| 需要连电脑 | 否 | **否** |
| 翻页方式 | 触摸手势模拟 | **真实物理按键 / 鼠标滚轮** |

核心原理：App 通过系统「无线调试」端口（127.0.0.1 本地回环）自行完成 ADB 握手与 RSA 认证，等同于系统内置的 adb 客户端，因此可以直接下发 `input keyevent` / `input roll` 这类真实的系统级输入指令。

## 五、CI 打包流水线做了什么

`.github/workflows/build-android-apk.yml` 的步骤：

| 步骤 | 作用 |
|---|---|
| Checkout | 拉取源码 |
| Set up JDK 17 | 安装 Temurin JDK 17（AGP 8.2.2 官方支持版本） |
| Set up Gradle | 启用 Gradle 缓存，加速后续构建 |
| Install SDK platform and build tools | 用 runner 预装的 sdkmanager 安装 platform-tools、platforms;android-34、build-tools;34.0.0 |
| Make wrapper executable | chmod +x gradlew（Linux 下脚本需要可执行权限） |
| Build debug APK | ./gradlew assembleDebug --no-daemon 真正编译出 APK |
| Upload APK artifact | APK 作为构建产物保存，可在 Actions 页面直接下载 |
| Publish release | 推 apk-debug-* 标签时自动创建 Release 并挂 APK |

## 七、手机端安装与使用（3 步）

### 安装
1. 从 GitHub Release 下载 `app-debug.apk`（或用数据线传到手机）。
2. 点开 APK，系统提示「未知来源应用」，允许当前浏览器/文件管理器安装。
3. 打开桌面上的 **随心滚 (独立极速版)**。

### 第 1 步：手机开启无线调试
1. 手机 【设置】 → 【开发者选项】 → 开启 **无线调试**；
2. 记下页面上「IP 地址和端口」，例如 `192.168.1.5:38421`。

### 第 2 步：App 内连接
1. 打开 App，在端口输入框填 `38421`（只填端口）或直接填 `192.168.1.5:38421`（填完整地址），点【连接】；
2. 手机弹出系统原生对话框「是否允许此设备进行调试？」→ 勾选【始终允许】→ 确定；
3. 状态变为绿色的「**本地 ADB 已连接 ✓**」。

### 第 3 步：开启悬浮窗
1. 点「悬浮窗权限 → 前往授权」，在系统设置里打开「显示在其他应用上层」，返回；
2. 打开「悬浮窗」开关，屏幕上出现控制条；
3. 进入抖音 / 快手 / 微信读书等任意 App，点悬浮窗的【⬆】【⬇】即可翻页。

### 翻页模式（主界面单选）

| 模式 | 实际下发的系统指令 |
|---|---|
| 物理键盘方向键 | `input keyevent 19` / `input keyevent 20` |
| 鼠标滚轮 | `input roll 0 1` / `input roll 0 -1` |

悬浮窗面板默认两档：折叠为 44dp 小圆球，展开后是【折叠 / 按键上 / 按键下 / 关闭】四个按钮。

## 八、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 连接失败 | 无线调试没开、端口号填错、或系统弹窗没点「始终允许」；v2.2.0 起可填 `IP:端口`，也可直接填端口让 App 自动探测 |
| 点了没反应 | 无线调试端口在重启后会变，需重新查看并重新连接 |
| 点了没反应 | 检查是否选中了「鼠标滚轮」模式（部分 App 不响应滚轮，可换回方向键模式） |
| 状态栏/刘海区域点不到 | 悬浮球拖到状态栏会触发系统手势拦截，拖到屏幕中下部 |
| 换新手机想装 | 直接下载 GitHub Release 里的 APK 覆盖安装 |
| CI 报 sdkmanager 失败 | 已修复，见提交 71311c2 |
