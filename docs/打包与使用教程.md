## 一、总体流程图

```
本地源码目录                     GitHub                    CI 构建机
FloatScroller/  --git push-->  WengHosea/FloatScroller  -->  Gradle assembleDebug
     |                                    |                          |
     |                                    |                    app-debug.apk
     |                                    |                          |
     +------------------------------------+------ artifact / release --> 下载安装到手机
```

关键点：仓库自带 `.github/workflows/build-android-apk.yml`，**每次 push 到 `main` 或推送 `apk-debug-*` 标签，GitHub 会自动构建 APK**，无需在本地装 Android Studio / Android SDK。

## 四、CI 打包流水线做了什么

`.github/workflows/build-android-apk.yml` 的步骤：

| 步骤 | 作用 |
|---|---|
| Checkout | 拉取源码 |
| Set up JDK 17 | 安装 Temurin JDK 17（AGP 8.2.2 官方支持版本） |
| Set up Gradle | 启用 Gradle 缓存，加速后续构建 |
| Install SDK platform and build tools | 用 runner 预装的 sdkmanager 安装 platform-tools、platforms;android-34、build-tools;34.0.0 |
| Make wrapper executable | chmod +x gradlew（Linux 下脚本需要可执行权限） |
| Build debug APK | ./gradlew assembleDebug --no-daemon 真正编译出 APK |
| Upload APK artifact | APK 作为构建产物保存，可在 Actions 页面直接下载 |
| Publish release | 推 apk-debug-* 标签时自动创建 Release 并挂 APK |

## 六、手机端安装与使用

### 安装
1. 用数据线把手机连电脑，或直接从 GitHub Release 下载 APK 到手机。
2. 点开 APK，系统提示「未知来源应用」，允许当前浏览器/文件管理器安装。
3. 装好后打开桌面上的 **随心滚助手**。

### 授权（关键，两步都要做）
1. **悬浮窗权限**：主页点「悬浮窗权限」按钮，跳到系统设置，打开「显示在其他应用上层」，返回。
2. **无障碍服务**：主页点「无障碍服务」按钮，在「已下载的应用 / 快捷服务」里找到 **随心滚助手**，打开开关，返回。

无障碍服务是本应用实现滑动模拟的核心（使用系统 `dispatchGesture`，免 Root、免电脑激活）。

### 使用
1. 主页打开「开启悬浮窗」开关，屏幕出现控制条。
2. 控制条上：
   - 上翻 / 下翻：切下一条视频、看书翻页
   - 播放键：开启自动定时翻页（3~30 秒可调）
   - 折叠按钮：收成半透明小圆球，不挡画面
3. 悬浮球可拖到屏幕任意边缘，松手自动贴边。

## 七、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 滑动没反应 | 没开无障碍服务，或 ROM 把悬浮球区域加入优化白名单 |
| 状态栏/刘海区域点不到 | 悬浮球拖到状态栏会触发系统手势拦截，拖到屏幕中下部 |
| CI 报 sdkmanager 失败 | 已修复，见提交 71311c2 |
| 换新手机想装 | 下载 GitHub Release 里的 APK 覆盖安装 |
